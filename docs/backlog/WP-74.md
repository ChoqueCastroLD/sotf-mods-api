## Decisions to confirm

- **Per-locale catalogue instead of Paraglide in these screens** · `features/upload/i18n.ts` · same approach as the console shell (`lib/messages.ts`): the source JSON of one locale formatted with `formatIcu`; `pnpm i18n:check` still validates every locale. Keys stay typed (`keyof en.json`); params are not type-checked per message.
- **Draft creation is lazy** · a draft is created on the first meaningful change (a file, a name…), not when the wizard opens, so browsing `/basecamp/new/mod` never consumes one of the 20 draft slots.
- **Free step navigation** · every step is reachable from the step bar; the review lists what blocks the submission (errors) with «Fix» links, and the step bar marks steps with blocking rows.
- **New version carries tested game builds** · the compatibility step is skipped for new versions, so «Game builds you tested» appears in the release step (the API's `testedGameBuildIds`).
- **Only the file blocks locally** · text fields are validated inline and invalid values are simply not saved (the server preflight reports what is missing); the submission is blocked by preflight errors only.
