# WP-15 backlog (changes outside `packages/markdown/**`)

One line per item: what · where · why.

- Record the pipeline changes as an ADR: PLAN §2.2 lists `remark-parse` + `remark-gfm` + `remark-rehype` + `rehype-stringify`; `@sotf/markdown` parses with `markdown-it@14.3.2`, keeps unified + `rehype-raw` + `rehype-sanitize`, and serialises verified trees with its own closed-set serialiser (rehype-stringify is the test oracle) · `docs/adr/**` (integrator / WP-00) · remark measured 48–69 ms for the 20 KB benchmark (budget 15 ms) and is super-linear on hostile input (20 KB of `*_*_` ≈ 18 s, `> > >` overflows the stack), a DoS of the API event loop; `hast-util-to-html` was a third of what remained; details in `packages/markdown/README.md` ("Why markdown-it").
- Promote the new exact pins to the catalog: `markdown-it@14.3.2`, `@types/markdown-it@14.2.0`, `@types/hast@3.0.5`, `rehype-raw@7.0.0` (runtime) and `showdown@2.1.0`, `@types/showdown@2.0.6`, `@types/jsdom@28.0.3` (tests only; showdown is the legacy renderer used as a test oracle, never shipped) · `pnpm-workspace.yaml` (integrator) · PLAN §12.1 shared-files rule; `remark-parse`, `remark-gfm` and `remark-rehype` can leave the catalog if no other package adopts them (`rehype-stringify` stays: test oracle).
- Prose styles for the pipeline's class hooks: `.md-anchor` (show on heading hover/focus), `.md-alert` + `.md-alert-{note,tip,important,warning,caution}` + `.md-alert-title`, `.md-spoiler` (blurred until `:hover`/`:focus`/`:focus-within`/`[aria-expanded="true"]`; visible focus ring on `[role=button]`; respect `prefers-reduced-motion`), `.md-youtube` (16:9 frame, play button over `.md-youtube-thumb`), `.md-mention`, `.contains-task-list`/`.task-list-item`, `details`/`summary` · `packages/ui/src/**` `prose-locator` (WP-12/WP-25) · the HTML contract is in `packages/markdown/README.md`.
- YouTube facade activation: on click of `a.md-youtube-link`, replace it with `<iframe src="https://www.youtube-nocookie.com/embed/{data-youtube-id}?autoplay=1&start={data-youtube-start}" allow="autoplay; encrypted-media; picture-in-picture" allowfullscreen title="…">` (localised title) · `apps/web/src/scripts/**` (WP-62) · the stored HTML has no iframe (CSP `frame-src` already allows youtube-nocookie); without JS the facade is a normal link.
- Spoiler reveal script (a11y requirement, not optional): on click, Enter and Space on `span.md-spoiler[role=button]`, set `aria-expanded="true"` and remove `role`, `tabindex` and `aria-label` so the revealed text is read normally (move focus to the span with `tabindex="-1"` to keep the focus position); spoilers that contain a link have no role and are revealed by CSS `:focus-within` · `apps/web/src/scripts/**` (WP-62/WP-70), axe check of a rendered spoiler (collapsed and revealed) in `e2e/**` (WP-91) · the stored HTML announces "Spoiler, button, collapsed" (localised `aria-label`, see the i18n item) and hides the text from assistive technology until revealed; without the script it can only be revealed visually by hover/focus.
- i18n messages for the HTML labels (alert titles `alert-note`, `alert-tip`, `alert-important`, `alert-warning`, `alert-caution`, and the spoiler accessible name `spoiler`; English defaults in `DEFAULT_LABELS`) and a call to `localizeHtml(html, labels)` wherever stored Markdown HTML is rendered · `packages/i18n/messages/<ns>/*.json` (WP-13/WP-94), `apps/web` components (WP-62, WP-70) · stored HTML is shared by the 13 locales, so it cannot contain translated text.
- Backfill B9: render **every** legacy description/changelog with `profile: 'legacyHtml'` (not only the 24 with raw HTML), store `RENDER_VERSION` in `renderVersion`, `decodeEntities` for `changelogMd`/`bodyMd`, and keep `descriptionMd` literal · `tooling/migration/**` (WP-14) · `legacyHtml` reproduces the legacy renderer (blank lines, `###Title`, Markdown inside HTML); `full` follows CommonMark and would re-flow legacy texts that relied on showdown.
- Persist the rendering profile with the content (e.g. `"Mod"."descriptionFormat" text` `'legacy' | 'markdown'`, default `'markdown'`, backfilled `'legacy'`) so an edited legacy description keeps rendering with `legacyHtml` until its author converts it, and have the editor warn when new Markdown contains raw HTML (`hasRawHtml`) · `packages/db/migrations/**` + `packages/core` publishing (WP-40, W4 migration range) · raw HTML is literal text in `full`; switching profile silently would break legacy layouts.
- Mentions: call `extractMentions(body)` before rendering, load the users in one query and pass a map-backed `resolveMention` returning `{ href: '/profile/{handle}' }`; notify the returned `mentions` · `packages/core` comments/reviews (WP-41) · the renderer is synchronous by design.
- Images inside descriptions: replicate `result.images[].src` to R2 (SSRF rules of PLAN §9.1) and re-render with `resolveImage` returning the R2 URL plus `width`/`height` · `apps/worker/src/jobs/media/**` (WP-40, B15) · avoids CLS and hotlinking; the CSP `img-src` only allows `r2.sotf-mods.com` and `i.ytimg.com`.
- Apply product length limits before calling the renderer (20 000 for descriptions, 2 000 for comments/reviews, 500 for bios) · `packages/contracts/src/**` (WP-11) · `MAX_MARKDOWN_LENGTH` (50 000) is only a hard safety ceiling.
- `POST /api/v2/markdown/preview`: call `renderMarkdown(md, { profile })` and return `{ html }` (lite/full only; never `legacyHtml` for user-chosen input unless the content is legacy) · `apps/api/src/modules/markdown-preview/**` (WP-70) · same pipeline as on write.
- Heading anchors use `aria-hidden="true" tabindex="-1"` (decorative, the heading itself is the accessible name); if WP-91's axe run prefers focusable permalinks, add a localised `aria-label` at render time with `localizeHtml`-style post-processing · `e2e/**` (WP-91) · Biome's `useAnchorContent` flags the pattern in HTML files, which is why `packages/markdown/biome.json` excludes the generated snapshots.
- Treat `links[].external` and the stored `href`s as browser-resolved (WHATWG `URL`, host-naming URLs serialised as `url.href`); do not re-derive hosts with regular expressions when moderating links, checking dead links or showing a "leaving the site" notice · `packages/core` comments and moderation, link checks, Ranger Station (WP-41, WP-51, WP-82) · the renderer already classifies `http:evil.com`, `https:\\evil.com` and `https://evil.com\@sotf-mods.com` as external.
