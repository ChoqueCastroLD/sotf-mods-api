# Backlog WP-02 (legacy hotfix)

- **check-forbidden (WP-00, `tooling/scripts/check-forbidden.ts`)**: exclude `ops/legacy-hotfix/**`. The `.patch` files necessarily contain the removed lines with `files.sotf-mods.com`, `FILE_UPLOAD_*` and `/preview`; `verify/seed.sql` reproduces the real row still stored on the retired host (to test the 410); the README documents it. Without the exclusion, `pnpm check:forbidden` fails on purpose-built fixtures.

- **Ownership (WP-00, `tooling/scripts/ownership.json`)**: WP-02 owns `ops/legacy-hotfix/**` and `docs/backlog/WP-02.md`.
- **Optional CI (WP-90)**: a manual job (`workflow_dispatch`) that runs `ops/legacy-hotfix/verify.sh` while the legacy is still in production. It needs Docker and network. It is not part of `pnpm ci:local`, because it clones the legacy repos from local paths (`LEGACY_API_REPO` / `LEGACY_FRONTEND_REPO` are configurable).
- **User (deploy)**: apply with `git am --keep-cr`, deploy API → frontend, delete the 5 leftover variables and add `R2_PUBLIC_BASE_URL` (steps in `ops/legacy-hotfix/README.md`). Plan §13.2 Q4: deployment recommended.
- **Known limit, not fixed in the hotfix**: the legacy API still trusts `?ip=` from any caller (it did before as well) and has no download rate limit. v2 fixes this with `ipHash`, `X-Internal-Auth` between web and API, and a non-counting limit (WP-31).
