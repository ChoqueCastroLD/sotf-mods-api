- **Platform overhead per request** · `apps/api/src/{app.ts,plugins/**}` (WP-20/WP-92) · a cached catalog read costs ≈ 1.1–1.7 ms of CPU in origin, of which ≈ 0.5 ms is the Zod response encoding and the rest the hook chain (helmet, cookie, CORS, CSRF, context HMAC, rate limit, ETag); closed-loop throughput ≈ 600 req/s per process on the dev host. Worth profiling before launch.
- **`@fastify/under-pressure` in tests** · `apps/api/src/app.ts` / `testing.ts` (WP-20) · with the shared host saturated (load average > 30) the ELU threshold 0.98 answers 503 to tests (`test/platform.int.test.ts` fails the same way on `main`); the catalog suites retry 503s with `Retry-After` (`injectCalm`). Consider disabling it in `buildTestApp`.
- **Web NSFW opt-in** · `apps/web` (WP-22/WP-81) · `GET /mods` is shared-cacheable: send `nsfw=1` only for visitors with `settings.nsfwOptIn`; cards and refs carry `nsfw` for blurring.
