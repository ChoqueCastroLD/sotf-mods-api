## Decisions taken (confirm or change additively)

- Legacy reset tokens are accepted when not expired **and** created less than 24 h ago; the window closes by itself after the cutover (the legacy stops creating them), so no env flag was added.
- Failed logins last at least 400 ms (`DEFAULT_FAILURE_FLOOR_MS`) on top of the decoy hash, so both failure branches take the same time; Turnstile is required after 3 failures in 15 min per IP hash or per account.
- New passwords are rejected when HIBP reports ≥ 1 breach; HIBP is fail-open (2 s timeout).
- Deletion anonymizes the "User" row (email `deleted-<id>@deleted.invalid`, handle `deleted-<id>`, name «Deleted survivor») instead of deleting it; comments, reviews, compat reports and moderation history stay; favorites, follows, kits, sessions, tokens, notifications and exports are deleted; downloads are unlinked. `keep_mods_anonymous` keeps the old handle in "UserSlugHistory" so the kept mods' URLs still resolve.
- One data export per user per 24 h (`RATE_LIMITED` with `retryAfter`).
