- **`pnpm e2e --grep @download`** · `e2e/**` (WP-91; WP-00 backlog asks for the Playwright project early) · there is no `e2e/` package yet, so the check cannot run. Stand-in: `apps/api/src/modules/downloads/web-route.int.test.ts` drives the web route core (`apps/web/src/pages/mods/[user]/[slug]/download/_proxy.ts`) with real `fetch` against the API over HTTP (302 + headers, UA-less client counted, HEAD/Range not, 404, bad secret → 503). CI should run it on a dedicated runner.

- **Inspection** · `apps/worker/src/jobs/inspection` · read the file from `Upload.bucket/key`, write `resultRef.inspection` in the `UploadInspectionDTO` shape (validated when served by `GET /uploads/:id`), set `Upload.status` to `ready` or `rejected` (`quarantineUpload` for flagged files).
