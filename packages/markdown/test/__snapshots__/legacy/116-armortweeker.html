This mod allows you to control the balance between the different types of armor to your liking. (multipliers: between 0.1 and 100)

Features:

  • Apply one multiplier for all types of Armor.
  • Apply a custom multiplier specific to each Armor type (Leaf, Deer, Bone, Creepy, Tech, Solafite).
  • Enable/Disable updating Equipped Armor durability.
  • Enable/Disable updating Damaged Armor pieces.
