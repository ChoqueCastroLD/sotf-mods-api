GolfcartTeleport is an innovative mod that lets players use a golf cart to teleport to their desired locations seamlessly. The user dont need to install anything!

How to use#

  • Type command in chat
  • Get into the newly spawned "ghost" golfcart.
  • Leave the golfcart as normal.

Commands:#

  • Access via inGame Chat:
  • user1: /tpa user2

    /tpr user2

    Side note, the username does not need to be exact.

  • user2: /tpaccept user1

    /tpyes user1

    /tpy user1

    Side note, the username does not need to be exact.

  • /home number

    "number" is required if more than 1

    (Default MaxHome is 1; adjustable in config)

  • /sethome number

    "number" is required if more than 1

    (Default MaxHome is 1; adjustable in config)

Why Golfcart:

No golf cart is needed. It spawns a golf cart in front of you. Get in and out.

Golfcart is for internal use, as this is a server-side mod.

This was the simplest solution I found since player position can't directly be changed from the server.
