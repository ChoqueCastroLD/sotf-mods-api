Warning#

Needs my SonsAxLib v1.2.0+ library to work, download it here: https://sotf-mods.com/mods/imaxel/sonsaxlib

Description#

If you ever felt like opening the inventory to equip an item is too slow, you now have a menu with up to 36 boxes to which you can assign an owned item and equip it with a click. You can only assign currently owned items, using the small red buttons and chosing an item from the list. If an item which you set isn't owned anymore, a red cross will appear on the box, meaning you can't equip it anymore.

Default opening key is LEFT ALT key. It can be changed from the mods settings.
