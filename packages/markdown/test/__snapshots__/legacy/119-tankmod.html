Spawning the tank#

Open the game debug console and type "spawntank" then press enter

Controls#

Enter the tank: game interaction key (default E)
Exit the tank: G key
Move: WASD
Rotate turret: Mouse X
Rotate muzzle: Mouse Y
Shoot: Left mouse button (1.5s delay between each shot)

Features#

-Removes trees along his path and those who are shot (only big ones)
-Can kill enemies, animals etc. with the shot

Additional camera controls in the mod settings. If tank get stuck, spawn a new one -> the previous will get destroyed.

Mod was made for fun, no further updates/features are planned.
