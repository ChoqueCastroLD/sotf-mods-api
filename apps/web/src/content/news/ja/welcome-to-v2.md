SOTF Mods は 2023 年から Sons of the Forest の Mod の拠点です。本日、サイトを全面的に作り直して公開しました。より速く、より安全に、そしてどのプレイヤーも最初に抱く疑問 ——**この Mod はまだ動く？**—— を中心に設計しています。

# 動く？ いまならわかります

各 Mod には、**現在のゲームビルド** で動作するとプレイヤーが確認したかどうかと、その根拠となるフィールドレポートの件数が表示されます。Mod を試したら、動いた・一部動いた・動かなかったを、ソロ、ホスト、クライアント、専用サーバーのどれで遊んだかと一緒に教えてください。クリエイターはバージョンをテスト済みとしてマークし、レポートに返信できます。

[Patch Radar](/patch-radar) は、ゲームのアップデートごとに人気上位 50 の Mod を、RedLoader と RedManager の状態とあわせて追跡します。パッチで何かが壊れたら、まずここでわかります。

# Mod を見つけて共有する新しい方法

- **探索** は本当に役立つフィルター付き：現在のビルドで動作、マルチプレイでの役割、専用サーバー、最近の更新。
- **Kit：** 一緒に使えるメモ付きの Mod コレクション。フォロー、複製して、仲間と共有できます。
- **レビュー** は評価付きで、スレッド形式のコメントとリアクションの横に並びます。
- Mod やクリエイターを **フォロー** すると、更新時に **Signals** が届きます。
- コマンドパレット：どこでも `Ctrl` + `K` を押すと、あらゆる Mod、ビルド、クリエイターへすぐに移動できます。

# クリエイターの方へ

**Basecamp** は新しいダッシュボードです。アップロード前に zip を確認するガイド付きの公開ウィザード、変更履歴付きのバージョン管理、ダウンロードとフィールドレポートの分析、対応が必要なことをまとめた受信箱を備えています。新しいクリエイターランクとバッジは、量ではなく質と貢献を評価します。

# より安全なダウンロード

新しい Mod はレンジャーステーションで審査され、ファイルはスキャンされ、各バージョンには SHA-256 チェックサムが表示されます。ログインのセキュリティも強化され、成人向けコンテンツは自分で有効にしない限り非表示です。

# あなたの言語で

サイト全体が 13 言語に対応しました。ウイルス対策の警告、BepInEx との混同、専用サーバー、よくある問題までカバーした [導入ガイド](/install) も含まれます。

# 変わらないこと

- **アカウント：** 同じメールアドレスまたはハンドルと、同じパスワードでログインできます。一度だけログインし直してください。
- **Mod、リンク、ダウンロード：** すべての Mod ページ、ダウンロードリンク、RedManager との連携はそのまま使えます。古いアドレスは新しいアドレスへ転送されます。
- **無料ダウンロード** は、アカウント不要で私たちのストレージから直接。

旧ワンクリックインストーラーは廃止しました。[RedManager](/install#oneclick) が同じことをもっとうまくこなします。
