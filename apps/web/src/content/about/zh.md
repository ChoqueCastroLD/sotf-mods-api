# SOTF Mods 是什么

SOTF Mods 是 **Sons of the Forest** 模组社区的家园。自 2023 年起，这里托管为游戏模组加载器 **RedLoader** 制作的模组、库和 BuildShare 建筑，是目前最大的 RedLoader 模组库。

所有内容都可以免费直接从我们的存储下载：无需账号、无需等待、无需下载器。社区的模组管理器 RedManager 读取的是同一个模组库，因此这里的任何模组都能一键安装。

# 由谁运营

网站由一支玩家和模组作者组成的小型志愿团队运营，并由 **版主** 负责管理：他们是社区的资深成员，负责审核新上传的内容并处理举报。网站代码在 [GitHub](https://github.com/ChoqueCastroLD/sotf-mods-api) 上开源。

模组属于它们的创作者。我们负责托管、展示并帮助大家找到它们；每个模组的荣誉和决定权都属于作者。

# 我们如何确保下载可靠

- 每个新模组在公开前都会由版主审核。
- 每个文件都会被扫描，每个版本都会显示大小和 SHA-256 校验值，方便你核对下载的文件。
- 任何人都可以举报模组、评论或评测；版主会迅速处理，每个操作都有记录。
- 成人内容默认隐藏，除非你主动开启。

允许发布的内容请参阅 [内容政策](/content-policy)。

# 网站如何维持

服务器和存储都需要花钱。未登录的访客会看到少量广告，但绝不会出现在下载按钮旁或安装步骤中；已登录的成员看不到任何广告。我们不出售个人数据，自己的统计也不使用 Cookie。详见 [隐私政策](/privacy)。

# 联系我们

最快的联系方式是社区的 [Discord](https://discord.gg/sotf)。隐私请求、版权通知或安全问题，请使用 [隐私](/privacy) 和 [DMCA](/dmca) 页面上列出的联系方式。
