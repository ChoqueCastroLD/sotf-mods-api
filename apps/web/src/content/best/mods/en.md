Sons of the Forest mods run on **RedLoader**, the community mod loader. This list ranks the mods on SOTF Mods by all-time downloads, so it shows what survivors actually install and keep.

Every card tells you whether the mod has been confirmed on the current patch, who needs it in multiplayer and which libraries it depends on. New to modding? Read [how to install mods](/install) first: it takes about five minutes.
