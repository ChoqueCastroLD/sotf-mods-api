Dedizierte Server führen das Spiel ohne Spieler an der Tastatur aus, deshalb laufen dort nur Mods, die für die Serverseite gebaut sind. Diese Liste sammelt Mods, die Unterstützung für dedizierte Server angeben oder für die Server-Plattform gedacht sind.

Installiere sie im RedLoader-Ordner des Servers, starte ihn neu und prüfe auf der Mod-Seite, ob Einstellungen zu übernehmen sind. Spieler brauchen eventuell trotzdem den Client-Teil einer Mod: Das Multiplayer-Label verrät es.
