I server dedicati eseguono il gioco senza un giocatore alla tastiera, quindi lì funzionano solo le mod pensate per il lato server. Questo elenco raccoglie le mod che dichiarano il supporto ai server dedicati o sono pensate per la piattaforma server.

Installale nella cartella RedLoader del server, riavvialo e controlla la pagina della mod per eventuali impostazioni da copiare. I giocatori potrebbero comunque aver bisogno della parte client: lo dice l’etichetta multigiocatore.
