Выделенный сервер запускает игру без игрока за клавиатурой, поэтому на нём работают только моды, сделанные для серверной стороны. В этом списке собраны моды, которые заявляют поддержку выделенных серверов или предназначены для серверной платформы.

Установите их в папку RedLoader на сервере, перезапустите его и загляните на страницу мода — возможно, нужно перенести настройки. Игрокам может понадобиться и клиентская часть мода: об этом говорит метка мультиплеера.
