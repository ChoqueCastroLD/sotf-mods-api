Dedicated servers run the game without a player at the keyboard, so only mods built for the server side work there. This list gathers mods that declare dedicated-server support or target the server platform.

Install them in the server's RedLoader folder, restart the server and check the mod's page for any setting to copy. Players may still need the client part of a mod: the multiplayer label says so.
