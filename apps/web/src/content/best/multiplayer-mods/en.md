Not every mod works in co-op, and the ones that do differ in who needs to install them. Each card on this list says it plainly: **only you**, **the host** or **every player**.

When everyone needs a mod, all players must run the same version, including its libraries. Mods marked "host only" must be installed by whoever hosts the game or runs the dedicated server.
