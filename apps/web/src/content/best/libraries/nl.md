Bibliotheken zijn gedeelde code waar andere mods op leunen. Je gebruikt ze zelden los: je installeert ze omdat een mod ze als vereiste noemt.

Installeer elke bibliotheek één keer, vóór de mods die haar nodig hebben, en houd haar bijgewerkt: als een patch een bibliotheek breekt, werkt geen enkele mod die ervan afhangt meer tot ze gerepareerd is. Elke modpagina toont haar afhankelijkheden met directe links.
