Les bibliothèques sont du code partagé dont dépendent d’autres mods. On les utilise rarement seules : on les installe parce qu’un mod les indique comme prérequis.

Installez chaque bibliothèque une fois, avant les mods qui en ont besoin, et gardez-la à jour : quand un patch casse une bibliothèque, tous les mods qui en dépendent cessent de fonctionner jusqu’à sa correction. Chaque page de mod liste ses dépendances avec des liens directs.
