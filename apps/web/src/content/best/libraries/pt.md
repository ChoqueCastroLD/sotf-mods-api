Bibliotecas são código compartilhado do qual outros mods dependem. Quase nunca são usadas sozinhas: você as instala porque um mod as lista como requisito.

Instale cada biblioteca uma vez, antes dos mods que precisam dela, e mantenha-a atualizada: quando um patch quebra uma biblioteca, todos os mods que dependem dela param de funcionar até ela ser corrigida. A página de cada mod lista as dependências com links diretos.
